## Specs
- Product type: Fire extinguisher (the masterlist states no agent and no size)

## Usage
These are general facts for this type of product, not the datasheet of CTI's unit. The masterlist states only the name of this product. Ask CTI sales for the agent and the size before you choose it. Each extinguisher label shows the classes of fire that it can put out. To use an extinguisher, pull the pin, aim low, squeeze the lever and sweep side to side.

## Advantages
- A portable extinguisher can put out a small, contained fire.
- Multipurpose extinguishers labelled A-B-C cover most home fires. Check the label to see which classes this unit covers.
- You can recharge some extinguishers. Others need replacement when the pressure is too low.

## Cautions
- Use an extinguisher only on a small, contained fire, and only when you have a clear escape route.
- If you are not sure that it is safe, alert others, leave the building and call emergency services.
- Check the pressure gauge if the unit has one. Look for damage, dents or rust on the body, hose and nozzle.
- U.S. workplace rules (OSHA) require a qualified person to inspect and pressure test portable extinguishers.
- Under OSHA rules, the employer must teach workers how to use a fire extinguisher.
